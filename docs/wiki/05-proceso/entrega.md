# Entrega del laboratorio

[← Proceso](README.md)

**Entrega requerida según la diapositiva:** URL del tag Git, repositorio público, README con configuración/ambiente/compilación/despliegue, scripts DDL y DML, código fuente y documento académico con portada, marco conceptual, diseño, procedimiento, conclusiones/lecciones y referencias.

## Antes de publicar `v1.0.0`

1. Ejecutar la demo completa y conservar evidencia verificable.
2. Confirmar `main` integrado, compilable y sin credenciales.
3. Verificar rutas MVC, las 20 operaciones REST, Swagger, FKs y errores.
4. Revisar que README contiene pasos **probados** desde un clon limpio.
5. Revisar el informe académico y su consistencia con SRS/SAD/SDD.
6. Crear tag anotado `v1.0.0` sobre commit de entrega y subirlo a GitHub.
7. Entregar URL directa del tag; la release de GitHub es opcional si el profesor no la exige.

No etiquetar una versión que todavía no haya pasado las verificaciones de entrega.
