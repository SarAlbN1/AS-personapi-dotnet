# Plantilla de issue para GitHub Projects

> Copiar este contenido al crear la issue real en GitHub; no reemplaza el backlog del Project.

## Objetivo

Como [actor], quiero [capacidad] para [resultado].

## Trazabilidad

- Requisito SRS: `RF-XX` / `RNF-XX`
- Decisión SAD: `AD-XX`
- Diseño o contrato: enlace a página wiki/SDD
- Módulo: [Core/Database/Personas/...]
- Sprint: [1/2]
- Responsable / revisor: [personas]

## Alcance y criterios de aceptación

- [ ] Resultado funcional verificable 1
- [ ] Resultado funcional verificable 2
- [ ] Errores / reglas de negocio verificados
- [ ] Prueba y evidencia E2E o justificación de alcance técnico
- [ ] Documentación afectada actualizada

## Dependencias

Solo issues o contratos realmente imprescindibles. Si existe bloqueo, explicar cómo reproducirlo.

## Definition of Done

PR revisado y fusionado, compilación/pruebas verdes y criterios verificados sobre comportamiento real.
